# Project agent resources

This directory holds reusable, project-specific agent skills. Skills live in
`.agents/skills/<skill-name>/SKILL.md` and are loaded when a task matches their
purpose.

Current skills:
- `econ-replication`: workflow for working through the Palma (2022) coursework.
- `local-projections`: implementation guidance for the impulse response task.

Keep student-facing coursework answers and completed solutions out of skills.
